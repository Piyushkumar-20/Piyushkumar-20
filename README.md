## Featured Projects

### MailPoint

AI-powered productivity workspace combining **Gmail and Google Calendar** into a unified application. Includes OAuth authentication, email and calendar workflows, AI agent capabilities, MCP-based tool integration, real-time updates, subscriptions, and multi-tenant architecture.

`Next.js` `TypeScript` `PostgreSQL` `Drizzle` `Better Auth` `tRPC` `Gmail API` `Google Calendar API` `MCP` `Groq`

### TripSync

Collaborative trip-planning platform with real-time itineraries, shared planning workflows, and role-based access control.

`React` `Node.js` `PostgreSQL`

### FlowForm

Full-stack form builder SaaS for creating, managing, and collecting custom forms and responses.

`TypeScript` `Express` `Drizzle` `PostgreSQL`

Standards-based authentication server implementing **OAuth 2.0 and OpenID Connect** concepts, deployed on Render.

`Node.js` `OAuth 2.0` `OpenID Connect`
